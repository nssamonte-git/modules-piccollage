# Creative ai-images engine

Provider-neutral image jobs, reconciliation and reversible acceptance.

```kotlin
implementation("noel.libs:core-creative-ai-images-engine:0.2.0")
```

Engine domain logic has no Android/Compose imports; Android adapters live in `data`. The engine does not pull Compose into your app.

See the [integration guide](../../docs/creative-libraries.md) and the sample app for working composition.
