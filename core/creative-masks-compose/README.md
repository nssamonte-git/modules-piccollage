# Creative masks compose

Source-space erase/restore masks and segmentation-mask adapter.

```kotlin
implementation("noel.libs:core-creative-masks-compose:0.2.0")
```

Themeable Compose components accept host state and callbacks. The host owns lifecycle, navigation, coroutines, and service adapters.

See the [integration guide](../../docs/creative-libraries.md) and the sample app for working composition.
