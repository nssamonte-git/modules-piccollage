# Threat Library

Retrieval-only threat cards: why it is a threat, how to find or test it, how to fix it. Pick a platform, then a cluster, then load exactly one card by id; never bulk-read this folder.

- [Shared](shared/MAP.md): 225 threats; ai-llm, auth, authz, availability, business-logic, config-infra, crypto, data-privacy, detection-ops, injection, iot-devices, network, offline-sync, payments, supply-chain
- [Android](android/MAP.md): 35 threats; integrity, ipc, permissions, storage, webview
- [Backend](backend/MAP.md): 42 threats; api-auth, api-authz, api-inventory, cloud, database, exploitation, graphql, messaging, post-exploitation
- [iOS](ios/MAP.md): 26 threats; auth, integrity, storage, webview
- [Web](web/MAP.md): 37 threats; browser, files, http, pwa, url

- Find a card by id, alias, CWE, or OWASP id: `sh scripts/query-threats.sh <pattern>`
- Conventions, dedup rule, and threat-modeling priorities: [README](README.md)

Generated by `sh scripts/build-threat-index.sh --maps`; edit card front matter, not these maps.
