# Unreviewed Generated or AI-Written Code

## Why It Is a Threat

Code generated by AI assistants, coding agents, or scaffolding is merged without security review, introducing insecure patterns, vulnerable or hallucinated dependencies (a `typosquatting`/`malicious-packages` vector, since attackers register commonly hallucinated names), and licensing or provenance issues at scale.

## How to Find or Test

Authorized testing only (follow the `smx-ai-vapt` authorization gate).

- Review AI-generated changes for insecure patterns and unverified or non-existent dependencies; confirm they meet the same review and test bar as human code.

## How to Fix

- Apply the same code review, SAST/SCA, and dependency verification to generated code; verify every suggested dependency exists, is the intended package, and is maintained.
- Require a named human owner to review and approve, and limit the repository and secret access of coding agents. Map to A03:2025, LLM09:2025, and `vulnerable-dependencies`.
