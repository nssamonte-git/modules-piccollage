# Rule catalog

Generated by `python3 core/tools/generate-rules.py` from the threat-library cards. Each rule cites the card that explains why the finding matters and how to fix it.

Severity is the rule severity. **critical** and **high** block the build by default; **medium** and **low** print as warnings. Rules marked *heuristic* in their message can produce false positives; accept those with a reasoned suppression.
